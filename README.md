# K-AI paper

Theoretical paper on AI capability when both inference and autonomous research require an allocable capital stock.

The maintained benchmark has one reproducible stock, allocated each instant among conventional production, AI inference, and AI research. The paper contains no numerical simulations.

Main theoretical results:

- If sigma_XL < 1, every regular nondegenerate infinite-horizon tail is labor-anchored and the inference and research shares of aggregate capital vanish.
- If sigma_XL = 1, an exact equilibrium BGP is constructed under eta + omega_X < 1 and sufficient curvature restrictions.
- If sigma_XL > 1, a regular bounded-capability tail is impossible and every regular AI-dominated branch reaches a finite-time singularity. This does not rule out irregular continuations.
